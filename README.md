# Асинхронный ИИ-автоответчик для Telegram на базе Pyrogram и локальной LLM

Высокопроизводительный юзербот для автоматизации диалогов в Telegram, построенный на базе фреймворка **Pyrogram** и локальной языковой модели **Qwen 2.5 (7B-Instruct)** с собственной LoRA-маской речи.

Проект спроектирован для максимально реалистичной имитации живого человеческого общения: естественные задержки перед прочтением, поддержание статуса набора текста, контекстная обработка ответов (Reply) и интеграция с CRM-таблицами Excel.

---

## 🚀 Ключевые возможности

1. **Локальный нейросетевой бэкенд (Transformers + PEFT / LoRA)**:
   - Полная автономность: генерация ответа на GPU (NVIDIA RTX) без внешних облачных API.
   - 4-битная квантование NF4 (`BitsAndBytesConfig`) для экономии видеопамяти (помещается в 8 ГБ VRAM).
   - Асинхронное исполнение GPU-инференса в пуле потоков (`asyncio.to_thread`) с защитой от race conditions (`asyncio.Lock`), что предотвращает блокировку event loop Pyrogram.

2. **Стелс-режим и человеческие таймлайны**:
   - **Пауза перед прочтением (1–5 сек)**: бот не заходит в сеть сразу и держит сообщение непрочитанным, имитируя человека, не смотрящего в экран.
   - **Параллельная генерация**: модель начинает думать одновременно со стелс-паузой, экономя время.
   - **Плавное появление в онлайне**: прочтение сообщения (`read_chat_history`) и циклическая отправка статуса `ChatAction.TYPING` каждые 4 секунды.
   - **Динамическая задержка (7–15 сек)**: если ИИ ответил быстрее, бот выжидает оставшееся время в статусе «печатает»; если дольше — сообщение уходит мгновенно.

3. **Поддержка Telegram Reply (Ответы на сообщения)**:
   - Автоматическое извлечение текста цитируемого сообщения с указанием автора (`[Ответ на сообщение Вани: "..."] Входящее сообщение девушки: "..."`).
   - Визуальное линкование (`reply_to_message_id`) собственных ответов, если собеседник ответил через Reply.

4. **CRM-учёт и динамический белый список**:
   - Автоматическая фиксация контактов и собранных фактов (имя, возраст, хобби) в Excel (`dates_{account}.xlsx`).
   - Синхронизация белого списка в трёх слоях: память -> JSON (`databases/whitelist.json`) -> `.env` (`WHITELIST_CHAT_IDS`).
   - Перехват маркеров приглашений на встречу с уведомлением в Saved Messages («Избранное»).

5. **Автоматизация сервисов знакомств (@leomatchbot / Дайвинчик)**:
   - Встроенный автолайкер с настраиваемыми лимитами и горячими командами управления (`.clicker on` / `.clicker off`).
   - Автоматическое распознавание взаимных симпатий и добавление новых контактов в воронку.
   - Защита ночного режима (строгий запрет на исходящие сообщения и пинги с 21:00 до 09:00).

6. **Полный MLOps-конвейер**:
   - `dataset_creator.py`: парсинг экспортов диалогов Telegram, глубокая фильтрация, анонимизация и сборка датасета JSONL.
   - `train.py`: нативный цикл PyTorch для LoRA-дообучения модели Qwen.
   - `inference.py`: интерактивная консоль для тестирования ответов модели перед запуском юзербота.

## 🛠️ Установка и запуск

### 1. Клонирование и виртуальное окружение

```bash
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
cd svaha_bot

python -m venv .venv
# Для Windows:
.venv\Scripts\activate
# Для Linux/macOS:
source .venv/bin/activate
```

### 2. Установка зависимостей

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

> **Примечание**: Для работы GPU-ускорения убедитесь, что установлен PyTorch с поддержкой CUDA (версия 12.1+).

### 3. Конфигурация окружения

Скопируйте шаблон `.env.example` в `.env`:

```bash
cp .env.example .env
```

Заполните переменные в `.env`:
- `API_ID` и `API_HASH`: получите на [my.telegram.org](https://my.telegram.org) в разделе «API development tools».
- `TELEGRAM_ACCOUNTS`: имя сессии (по умолчанию `acc_main`).
- `BASE_MODEL`: базовая модель HuggingFace (по умолчанию `Qwen/Qwen2.5-7B-Instruct`).
- `ADAPTER_PATH`: путь к папке с обученными LoRA-весами (по умолчанию `./vanya_lora_weights`).

### 4. Создание сессии Telegram

Авторизуйтесь в аккаунте через официальные ключи Telegram Desktop:

```bash
python session_maker.py
```

Скрипт создаст файл сессии в папке `sessions/acc_main.session` и сохранит строку `SESSION_STRING` в `.env`.

### 5. Запуск юзербота

```bash
python userbot.py
```
